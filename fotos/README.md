# Fotos de Inako

Copia aquí todas las imágenes que quieras mostrar. Puedes crear subcarpetas y usar archivos JPG, JPEG, PNG, WEBP, GIF o AVIF.

Puedes organizar las fotos en subcarpetas como `Retratos`, `Favoritas` o `Recuerdos`. La web convertirá esas subcarpetas en filtros automáticamente.

Después, desde la carpeta principal del proyecto, ejecuta:

```bash
npm run galeria
```

Esto actualiza `fotos.json`; al volver a abrir la web aparecerán automáticamente todas las fotos.

> También puedes pulsar **Elegir carpeta** en la página para previsualizar una carpeta al instante, sin modificar archivos.
